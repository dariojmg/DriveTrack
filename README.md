# DriveTrack

DriveTrack is a native Android GPS trip logger. It shows an analogue speedometer, distance, elapsed time, saved journeys, trip statistics, and a locally drawn GPS route.

## Install

Open **Actions → Build DriveTrack APK → latest successful run → Artifacts → DriveTrack-APK-debug**, download the ZIP, extract `DriveTrack.apk`, and tap to install. You may need to allow *Install unknown apps* for your browser or Files app. This debug-signed beta APK can be updated with future builds only if the same signing certificate is retained.

No journey data is uploaded. GPS tracking uses a foreground Android location service and displays a persistent notification.

Do not use this app while actively driving; interact with it only when stationary.
